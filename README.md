# Equipment Rental Rangpur (Client)

Frontend web application for Equipment Rental Rangpur.It is an equipment rental marketplace where owners list equipment and customers browse, book, and pay securely online.

## Live URL
- Client: https://rangpur-rental-client.vercel.app
- Server: https://rangpur-rental-server.vercel.app

## Key Features
- Responsive public Home Page (Framer Motion animations) and All Equipment marketplace with server-side search, filter, and sort
- Role-based authentication with Better Auth (Email/Password + Google Login) and JWT verification
- Private Equipment Details with Favorites, Booking Modal, and Stripe Checkout
- Full-width Customer, Owner, and Admin Dashboards with Recharts analytics
- ImgBB image upload and Dark/Light Theme Toggle
